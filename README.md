# Interactive Calculator & Unit Converter

## About
A Python-based command-line application that performs basic arithmetic operations and unit conversions.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Kilometers to Miles
- Celsius to Fahrenheit
- Input validation using while loops
- Division by zero protection
- Continuous menu until the user selects Quit

## Technologies Used
- Python 3

## How to Run
1. Download the project.
2. Open the terminal in the project folder.
3. Run the following command:

`python Calculator.py`

- Kilometers to Miles
- Celsius to Fahrenheit
